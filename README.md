# Santa

A private Secret Santa site for one family: pair-rule draw, scratch-card reveal, anonymous Santa threads, family chat, wishlists and secret ideas. Next.js + SQLite on the home-lab mini PC; guests log in with their first name.

Needs Node 24+ (`nvm use` reads `.nvmrc`). Run locally with `npm install && npm run playground && npm run dev` (log in with a first name; Axel uses PIN `0000` and the 🧪 panel switches identity). Playground seed + troll gift draw: [docs/playground.md](docs/playground.md). Deploying, rehearsing and wiping: [docs/runbook.md](docs/runbook.md).
